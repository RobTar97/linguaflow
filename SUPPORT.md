# Support

LinguaFlow is maintained by its open-source community.

- For reproducible defects, use the bug-report issue form.
- For product ideas, use the feature-proposal form.
- For new curriculum, use the topic-card form and content guide.
- For substantial platform functions, read `docs/OPEN_PLATFORM.md` and use the
  feature-proposal form before implementation.
- For help finding the right guide, start at `docs/README.md`.
- For private security concerns, follow `SECURITY.md`.

Before opening an issue, run `npm run check`, search existing issues, and
include the affected role, language direction, CEFR level, browser, and device.
Do not publish student names, room codes from active classes, or other private
classroom information.
