# Landing-page experience

The public homepage has one job: help an adult learner, teacher, or student
understand LinguaFlow and enter the right workspace path with confidence. It is
an editorial introduction to conversation practice, not a second application
dashboard.

## Experience contract

The page leads with the promise “Talk about something real,” then explains the
three decisions that begin practice: choose a language direction, choose a
worthwhile subject, and speak independently or in a teacher-led room. Role
links carry a validated `role=learner`, `role=teacher`, or `role=student` hint
into the existing three-step setup flow. A valid room invitation still takes
precedence and opens setup as a student.

The homepage must remain useful without JavaScript. Its HTML and cacheable
`/landing.css` stylesheet are generated by
[`scripts/seo-static-pages.ts`](../scripts/seo-static-pages.ts), while the
interactive workspace continues to live under `/app/`. Public curriculum,
teacher, privacy, about, and source links remain ordinary crawlable links.

## Visual and motion system

The visual direction is a multilingual conversation atelier for adults:
ink-blue typography, paper-like blue-white space, cobalt actions, coral
emphasis, and mint or lilac editorial accents. Large condensed headlines,
ruled lists, an intentionally clipped session image, and one prompt sheet avoid
generic dashboard cards, floating feature chips, and ornamental statistics.

The multilingual ribbon is the single continuous motion signature. Entrance
and optional view-based reveals use only opacity and transforms. Motion is
disabled under `prefers-reduced-motion: reduce`, including the ribbon, and all
content remains fully visible. Interactive targets are at least 44 pixels high
and keyboard focus uses a high-contrast coral outline.

## Content and performance rules

- Keep the primary action singular and concrete: start speaking.
- State account, recording, transcript, grading, advertising, and room-expiry
  boundaries accurately; do not imply speech recognition or AI tutoring.
- Preserve the 48-topic and 288-question facts only while the catalog supports
  them.
- Use the optimized 720- and 1200-pixel WebP session images already in
  `public/images`; avoid external fonts, trackers, and homepage JavaScript.
- Keep the generated homepage above the SEO audit's substantive-copy threshold
  and within the repository's HTML and image budgets.
- Prefer one featured topic from every curriculum category over a dense grid of
  every available topic; the localized hubs remain the complete directories.

## Review checklist

Run `npm run check`, then inspect `/` and `/app/?role=learner` from a production
preview at desktop and 375-pixel mobile widths. Confirm there is no visible
horizontal overflow, the header and actions remain readable, sections appear
without animation support, keyboard focus is clear, and reduced-motion CSS
removes every nonessential animation. Test all three role URLs and verify a
`?room=AAA-999` invitation still selects the student role.
